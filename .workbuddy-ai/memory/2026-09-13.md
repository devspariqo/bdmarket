# 2026-09-13 — PHP + MySQL rewrite completed

## What was built

Rewrote the BD Market eCommerce project from Next.js/Prisma/SQLite to **plain PHP + PDO + MySQL** for shared-hosting deployment.

- `php/index.php` — front controller with PATH_INFO fallback.
- `php/routes/store.php` — 18 storefront handlers.
- `php/routes/admin.php` — 17 dashboard handlers with role-based capability gating.
- Core libraries: bootstrap, db, helpers, settings, auth, cart.
- 20-table MySQL schema + idempotent seed.
- 52 PHP view files, linted clean on PHP 8.0 and 8.2.
- `assets/css/app.css` + `assets/js/app.js` — single file, no build step.
- `README.md` with full setup + troubleshooting guide.
- `bd-market-php.zip` — 0.13 MB upload-and-run package.
